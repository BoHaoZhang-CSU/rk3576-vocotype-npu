## 一句话卖点（挑一个当封面）

- **「给 Linux 输入法装个 NPU 加速：CPU 占用降到 1/140」**
- **「同样快，但电脑不卡了：把语音识别从 CPU 挪到 NPU」**
- **「500 块的开发板，离线语音输入，CPU 几乎不干活」**

第三个最好，因为「离线 + 不占 CPU」是这台机器真正的差异点。

---

## 核心叙事（这三幕撑起整个视频）

### 第一幕：钩子 —— 反直觉的数字

大家谈 NPU 加速都谈「快了多少倍」。这个项目墙钟只快 5～12 倍，**不算惊艳**。

但看另一个数字：

| | 墙钟 | **CPU 时间** |
|---|---|---|
| CPU 识别 29 秒音频 | 7.25 s | **28.1 s** |
| NPU 识别同一段 | 0.96 s | **0.20 s** |

**CPU 时间差两个数量级。** 识别的时候，这台机器是「闲」的。

> 关键台词：
> 「墙钟快 7 倍，听起来一般。但你看 CPU 时间 —— 从 28 秒降到 0.2 秒。
> 意思是你说话的时候，电脑完全没在忙。这个才是开发板上最值钱的东西。」

**画面**：分屏。左边跑 CPU worker，`htop` 四个核全红。右边跑 NPU worker，
`htop` 几乎全绿但文字照样出来。**这是整个视频最有说服力的一组镜头。**

### 第二幕：怎么做的 —— 不改上游一行代码

> 「VocoType 的 worker 是个独立进程，跟核心用 JSON-lines 通信。
> 所以只要写一个说同样协议的新 worker，改一行配置就换掉了。上游一行代码没动。」

**画面**：一张架构图（README 里有 ASCII 版，可以做成好看的图）。

```json
// 就这一行
"worker_path": "/home/你的用户名/.local/bin/vocotype-offline-worker-npu"
```

### 第三幕：坑 —— 最有信息量的部分

**主推这个**：NPU 内存是跨进程共享的有限池。

> 「普通内存还剩 6.4 GB，NPU 却分配不出来 —— 因为 NPU 侧那个池子只有 2.2 GB，
> 而且是**全系统共享**的。
>
> 更坑的是：sherpa-onnx 的 C++ 层遇到这种情况**直接 exit(255)**，
> Python 的 try/except 完全接不住。你从 Python 那边看，就是进程莫名其妙没了，
> 一行有意义的日志都没有。」

**画面**：终端里重现这个崩溃，`echo $?` 显示 255。
这个「看不懂的失败」比成功案例更能体现踩坑的价值。

### 杀手镜头：htop 对比

```bash
# 左边窗口：原版 CPU worker。同时开 htop，截取四个核全满的画面
ONLY=cpu .venv/bin/python3 tools/bench_cpu_vs_npu.py 29s.wav

# 右边窗口：NPU worker。htop 里 CPU 基本不动
ONLY=npu .venv/bin/python3 tools/bench_cpu_vs_npu.py 29s.wav
```

> 两个 worker **不能同时跑** —— 会撞 NPU 内存池直接崩（`exit(255)`，
> 这本身也是个可以拍的花絮）。所以脚本用 `ONLY` 环境变量把两边分开跑。
> 一次跑全（不加 `ONLY`）也行，脚本内部会**轮流**启动两个 worker。

### 演示「按 F9」的两种拍法

**A. 有麦克风**（推荐，最直观）：

1. 打开任意文本框（gedit / 浏览器地址栏）
2. 按 F9 → 屏幕下方的录音标志出现
3. 说一句话 → 再按 F9 → 文字出现在光标处
4. 全程任务管理器开着，CPU 几乎不动

**B. 没麦克风**（本机当前状态：麦克风被物理拆了）：

核心暴露了一个 Unix socket，可以直接灌 wav 文件，走的是**同一条路径**：

```bash
.venv/bin/python3 tools/ask_core.py 你的音频.wav
```

拍这个也能说明问题，但要**在视频里说清楚**「这里是用文件模拟麦克风，
实际按 F9 走的是同一条路」—— 别让人以为是假的。

## 几个「一句话就能讲清」的知识点

这些适合当转场字幕：

- **RK3576 的 NPU 是双核的。** 验证方法：开两个上下文并发，单次只慢 1.25×
  而吞吐到 1.61×。如果是单核，单次会慢 2 倍、吞吐不动。
- **固定形状模型有代价。** 10 秒档的模型，你说 3 秒它也按 10 秒算 ——
  所以短句用 5 秒档，168 ms vs 270 ms。
- **别用 VAD 切长音频。** 会切在词中间丢字。改成在能量最低处切。
- **PyPI 的 sherpa-onnx 不带 RKNN。** 一句话就能帮观众省半天：
  查扩展模块里有没有 `offline-paraformer-model-rknn` 这个字符串。
- **NPU 内存不是普通内存。** 单独一个池子，全系统共享，超了进程直接死。

## 别在视频里说的话

- ❌「比 CPU 快 140 倍」—— 墙钟是 5～12 倍，1/140 是 **CPU 时间**。混着说会被人抓。
- ❌「我做的 VocoType」—— VocoType 是别人的项目，本项目只是外挂 worker。
- ❌「RK3588 也能用」—— 理论上可以，但没实测过。

这一个镜头就把「为什么要上 NPU」讲完了，比任何数字都直观。
