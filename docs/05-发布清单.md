## 3. 提交前必须决定的：`dist/*.whl` 怎么办

那个 15 MB 的预编译轮子是**别人能不能「直接就用」的关键**（省 25 分钟编译），
但不该进 git 历史 —— **一旦提交，就永远留在历史里了**，仓库会一直背着这 15 MB。

三个选择：

| 方案 | 说明 |
|---|---|
| **A. 传到 GitHub Release（推荐）** | 仓库干净，别人从 Release 下载。`install.sh` 已经支持 `VOCOTYPE_NPU_WHEEL=<路径>` |
| B. 不管，就这样 | 收到代码的人得自己编。README 里给了完整配方 |
| C. 直接提交进仓库 | 能用，但仓库 +15 MB 且不可撤销。**不建议** |

已经在 `.gitignore` 里排除了 `dist/*.whl`，所以默认走方案 A/B。
`dist/README.md` **会**被提交（它是说明文档，不是二进制）。

```bash
cd /home/radxa/wp/vocotype-npu
git init -b main
git add .
git status          # 确认没有 .venv/ models/ dist/*.whl 混进去
```

**提交前务必看一眼 `git status`。** 确认这三样没被加进去：
